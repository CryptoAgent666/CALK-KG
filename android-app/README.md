# Calk.KG Android App

Android-приложение для Calk.KG на базе **Trusted Web Activity (TWA)**.

## 📱 Описание

Это нативное Android-приложение, которое открывает сайт calk.kg в полноэкранном режиме, как обычное приложение (без адресной строки браузера).

## 🛠 Требования

- **macOS** с Homebrew
- **JDK 17** (устанавливается автоматически)
- **Android SDK** (устанавливается автоматически)

## 🚀 Быстрая сборка (без Android Studio!)

### Шаг 1: Установите зависимости (один раз)

```bash
brew install openjdk@17
brew install --cask android-commandlinetools
brew install gradle
```

### Шаг 2: Соберите Debug APK

```bash
cd android-app
./build.sh debug
```

APK будет в: `app/build/outputs/apk/debug/app-debug.apk`

---

## 📦 Сборка Release для Google Play

### Шаг 3: Создайте keystore для подписи

```bash
cd android-app

# Создайте папку для ключей
mkdir keystore

# Сгенерируйте ключ
keytool -genkey -v -keystore keystore/calk-kg-release.keystore \
  -alias calk-kg \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000
```

**Запомните пароли!** Они понадобятся для публикации.

### Шаг 4: Получите SHA256 fingerprint

```bash
keytool -list -v -keystore keystore/calk-kg-release.keystore -alias calk-kg
```

Скопируйте значение `SHA256:` (без пробелов, заглавные буквы, через двоеточие)

### Шаг 5: Обновите assetlinks.json на сайте

Замените `YOUR_SHA256_FINGERPRINT_HERE` в файле:
```
public/.well-known/assetlinks.json
```

на ваш SHA256 fingerprint.

**Загрузите обновлённый файл на хостинг**, чтобы он был доступен по адресу:
```
https://calk.kg/.well-known/assetlinks.json
```

### Шаг 6: Настройте подпись через keystore.properties

⚠️ **ВАЖНО:** Никогда не храните пароли в `build.gradle`! Используйте отдельный файл `keystore.properties`, который не попадает в git.

1. Скопируйте шаблон:
```bash
cp keystore.properties.example keystore.properties
```

2. Откройте `keystore.properties` и заполните реальными значениями:
```properties
storeFile=../keystore/calk-kg-release.keystore
storePassword=ВАШ_РЕАЛЬНЫЙ_ПАРОЛЬ
keyAlias=calk-kg
keyPassword=ВАШ_РЕАЛЬНЫЙ_ПАРОЛЬ
```

3. Файл `keystore.properties` уже добавлен в `.gitignore` — он НЕ попадёт в репозиторий.

`build.gradle` автоматически прочитает значения из этого файла при сборке release.

### Шаг 7: Соберите APK/AAB

**Для тестирования (APK):**
```bash
./gradlew assembleRelease
```

APK будет в: `app/build/outputs/apk/release/app-release.apk`

**Для Google Play (AAB):**
```bash
./gradlew bundleRelease
```

AAB будет в: `app/build/outputs/bundle/release/app-release.aab`

## 🚀 Публикация в Google Play

### 1. Создайте аккаунт разработчика

Зайдите на [Google Play Console](https://play.google.com/console) и зарегистрируйтесь ($25 единоразовый платёж).

### 2. Создайте приложение

1. Нажмите **"Создать приложение"**
2. Заполните информацию:
   - Название: `Calk.KG - Калькуляторы Кыргызстана`
   - Язык по умолчанию: Русский
   - Тип: Приложение
   - Бесплатное/Платное: Бесплатное

### 3. Заполните описание магазина

**Краткое описание (до 80 символов):**
```
Бесплатные онлайн калькуляторы для жителей Кыргызстана
```

**Полное описание:**
```
Calk.KG — крупнейший сервис бесплатных онлайн-калькуляторов для жителей Кыргызстана.

📊 БОЛЕЕ 25 КАЛЬКУЛЯТОРОВ:

💰 Финансовые:
• Калькулятор зарплаты — рассчитайте чистую зарплату с учётом налогов
• Кредитный калькулятор — ежемесячные платежи и переплата
```

### 4. Загрузите скриншоты

Нужны скриншоты размером:
- Телефон: 1080x1920 или 1080x2400 (минимум 2 шт.)
- Планшет 7": 1200x1920 (опционально)
- Планшет 10": 1600x2560 (опционально)

### 5. Загрузите иконку

- Размер: 512x512 PNG
- Используйте красный фон (#DC2626) с белым калькулятором

### 6. Загрузите AAB файл

В разделе **"Производство" → "Релизы"**:
1. Создайте новый релиз
2. Загрузите файл `app-release.aab`
3. Добавьте примечания к релизу

### 7. Заполните декларации

- Рейтинг контента: PEGI 3 / IARC 3+
- Реклама: Да (если используете AdSense)
- Целевая аудитория: 13+ лет
- Политика конфиденциальности: https://calk.kg/privacy-policy

### 8. Отправьте на проверку

Проверка занимает 1-7 дней.

## 🔧 Обновление приложения

1. Увеличьте `versionCode` и `versionName` в `app/build.gradle`
2. Соберите новый AAB
3. Загрузите в Google Play Console
