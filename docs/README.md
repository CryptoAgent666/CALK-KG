## Обязательное правило

Любое значимое изменение в проекте должно сопровождаться новой записью в [WORKLOG.md](./WORKLOG.md).

Без записи в журнале работа считается незавершённой. Это относится к:

- изменениям кода;
- обновлению данных, переводов и SEO-контента;
- деплою, откату и ручным правкам на проде;
- запуску скриптов, которые меняют `dist`, статику или конфигурацию.
